# Day 06 - Linux File I/O Practice

## Commands Practiced

1. touch notes.txt - Created an empty file.
2. > - Wrote text to a file.
3. >> - Appended text without deleting existing content.
4. tee -a - Writes and displays text while appending.
5. cat notes.txt - Displays complete file content.
6. head -n 2 notes.txt - Displays the first two lines.
7. tail -n 2 notes.txt - Displays the last two lines.

## Learning

Practiced basic Linux file creation, writing, appending and reading operations.
